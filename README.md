# Weather App 🌦️

A real-time Weather Application built using HTML, CSS, and JavaScript with OpenWeather API integration to provide live weather updates for different locations. The application displays temperature, humidity, wind speed, and weather conditions through a clean and responsive user interface.

The app also includes Geolocation support to automatically detect the user’s current location and fetch accurate weather details instantly.

---

## 🚀 Features

- Real-time weather updates
- Current location weather using Geolocation API
- City-based weather search
- Temperature, humidity, and wind speed display
- Responsive and interactive UI
- Dynamic weather icons and conditions
- Fast API data fetching using OpenWeather API

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
- Geolocation API
